# 更新日志

## v1.0.3

* 缩短辅助相机的等待时间由之前的2s改成500ms
* 打包箱号识别数据的时候,加入time_value参数,从缓存冲取值的时候,需要根据time_value来判断是否过期,过期则不取
* 缩短获取识别结果的时间,从之前的100ms改成10ms
* Container Record Video数据如果是ftp地址的话,需要保持和同方威视的json格式一致,否则会卡口导致解析失败
* 修复Restful接口开始时间的偏移问题,需要减去time_value的值
* 顶相机的检测间隔时间为500ms,左右相机的检测间隔时间为2000ms
* 如果辅助相机出现识别结果一样的情况下，需要继续开启检测只是一个集装箱结束,而不是整个车次结束,否则导致只识别了一个集装箱
* 只有在打包的时候才会需要判断是否过期,其他时候不需要判断
* 修复双箱号识别成单箱的问题
* 主要是由于箱数判断错误,当前钱后相机都为空的时候,不能作为判断条件,使用前后箱号判断的依据就是箱号识别对
* 日志输出识别次数,方便调试
* 补全的箱号打包的时候不参与根据箱号判断数量的函数
* 打包的过程中判断是否是长集装箱需要满足得分的条件
* 箱号的数字部分如果完全一致,则认为相似,不在需要比较相似度
* 容易误识别的添加HEGU,修改成REGU
* 修复了缓存的问题,key用错了,应该用相机名称作为key,而不是相机信息
* 升级jade_tools库,优化RtspInfo,新增编码加速器类型和编码加速器参数

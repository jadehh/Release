# 更新日志

## v1.0.2

* 相机新增TimeOffset参数,用来调整相机的时间偏移,默认是0,有的项目会遇到左右相机不同时识别,需要调整这个参数,来解决这个问题
* 存在的问题,车辆识别结束后通知检测线程开始检测的时候,会有延迟,导致多识别了几张图,并且这几张图都有识别结果，这样会导致下一辆车开始识别的时候取到这个识别结果
* 解决方法,首次识别的时候先清空缓存,后续将识别结果添加到缓存中
* 该问题的影响:会导致下一辆车直接获取到了识别结果,而不是在继续识别。
* 设计上的缺陷就是:检测队列与获取识别结果的队列通知检测队列暂停的是不同了，无法做到立马通知立马暂停,无法避免这样的情况

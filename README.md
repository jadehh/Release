## 更新时间 
2026-09-10 15:59:40 
# 更新日志

## v1.0.5

* 升级inference依赖到v1.0.3版本
* 添加内存泄漏检测的文档
* 重新设计评分机制,修改集装公司,箱号,和箱型的权重
* 为每个相机添加识别区域,识别区域外的结果忽略,识别区域的划分与算坊工坊的相机的区域一致,识别区域的是不可更改的
* 箱号识别服务加入检查集装箱公司参数,默认开启,如果关闭,则不会检查集装箱公司,检查集装箱公司的目的防止识别到的箱号不在海运注册中,替换为海运注册中的箱号
* 如果当前时间与缓存中的时间差大于time_value,应该直接返回结果
* 优化有箱型但是没有识别出来的权重
* 优化箱号日志输出
* 暂停检测的前提是箱号识别成功,可以暂停,如果箱号识别分数低,则继续检测
* 修复同方威视对接的bug
* 修复箱号去重合并的bug,会导致内存乱码的问题
* 代码清理,删除一些冗余的代码
* 对接同方威视的时候,不需要超时等待,但是支持提前返回结果,因为同方威视是只支持停止操作的。
* 提交箱号功能描述
* 支持箱型25B0的支持
* 新增时间偏移参数,解决现场车辆行驶太快的问题,导致箱号取不到,或者取不完整的bug
* 新增过滤集装箱检测框的参数,默认开启,如果关闭,则不会过滤集装箱的检测框,如果开启,则会过滤掉一些错误的集装箱检测框,开启主要防止误检测,但是有的现场不能过滤,不然会导致检测不到集装箱
* 处理模式统一修改成process_mode
* 取图流程,如果前后相机出现误识别,应当优先选择正确识别的箱号图,而不是按照时间选择
* 按照类别过滤只有左右相机才可以不过滤,前后相机不受参数控制
* 取值的时间不管服务类型,使用同样的参数配置
* 删除不必要的参数,只保留必要的参数

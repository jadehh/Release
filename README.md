# 更新日志

## v1.0.1

* 优化最佳箱型取值的结果,必须要箱型检验通过才行,不能直接取得分最高的箱型
* 优化相似度判断,根据相似度/箱号得分,判断是否相似,相似则认为是同一个箱号
* 分相计算之前需要判断相似度是否满足条件,满足条件的才会进行分相的计算
* 最多识别的数量为12
* 新增CameraCaptureOrder参数,用来区分不同的相机的识别顺序,默认是不开启,开启后,会根据相机的识别顺序,来判断是否是跟车
* 使用更多数据来进行测试相似度判断规则
* 添加MHSU转换成WHSU的规则,优化相似度计算的规则,使用完整的箱号计算相似度和仅使用数字计算相似度,取两个相似度的平均值作为最终的相似度
* 修复windows上md5值获取不到的bug
* Windows下发布json文件报错的bug
* Windows下使用bat文件进行编译,修复命令不识别的问题
* 修复Workflow的配置文件,修复了文件路径问题
* 修复md5计算的bug
* 更新Release上的触发条件,只在ContainerOCRService-v*标签触发,其他标签不触发
* 分支已存在
* 修改README.md的输出文件
* 修复文件编译产物的路径问题,完善workflow的配置文件

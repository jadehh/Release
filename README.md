# 更新日志

## v1.0.4
* 修复没有识别结果将图片删除的bug,优化获取识别结果的逻辑,在没有识别结果的时候,直接开启检测,重新识别
* 新增双箱相似度是否需要判断的参数,解决内河现场拉两个相似的集装箱返回一个箱号的问题
* 新增侧相机是否开启检测箱门的功能,解决内河现场侧面集装箱有箱门的情况
* 新增忽略集装箱检测高度比的参数,解决内河现场车辆停住之前,没有完全经过前相机，导致高度比较低,导致忽略了集装箱
* 修改参数名称,从ignore_container_detection_height_ratio改为ignore_container_height_ratio
* 区分正常退出和异常退出,正常退出是主服主动退出,异常退出是服务异常退出,需要清理资源
* 调整参数名称
* 优化判断缓存中的集装箱是否过期的逻辑
* Restful接口支持版本如V1,V2,V1就是之前默认的版本,V2就是新的版本
* ContaExtra字段需要根据配置的版本号返回接口的版本,V2版本才支持url图片地址,v1版本和其他版本的接口只支持Base64编码数据,默认是Base64编码数据
* 修改Restful接口楼的参数名称
* V1版本的接口不在使用版本号
* Debug日志输出返回结果,并且打印包的大小
* 修复缓存根据过期时间判断是否过期的问题,需要根据time_value来判断是否过期
* 修复Modbus监听时间和重连时间顺序反了的bug
